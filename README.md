# Solana Number Guessing Game

A simple on-chain number guessing game where:
1. Program generates a random number (using recent blockhash for randomness)
2. Player makes guesses by sending transactions
3. Program provides feedback (higher/lower)
4. Player wins by guessing correctly within allowed attempts

## Features
- On-chain game state tracking
- Secure random number generation
- Limited attempts per game
- Simple client interface

## Technical Stack
- Solana Program (Rust)
- TypeScript Client
- Web3.js
- Anchor Framework
